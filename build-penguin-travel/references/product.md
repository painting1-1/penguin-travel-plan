# 功能与数据规则

## 稳定数据
将数据和渲染分离；为 day/event/place/person/bill/task 使用稳定 ID。
改名称时间、插入活动不重建旧 ID，保持攻略、勾选、个人编辑与关联任务。
地点查询、坐标、精度、活动关系集中维护，地图和导航读同一份数据。

## 行程
按日期、时间排序，显示城市、住宿/过夜交通、活动、转场与预约。
跨国起降说明当地时区。固定班次从终点倒推；明确回酒店取箱、到车站机场缓冲。
不能用“人少”假定无堵车。动态事实核实或标待确认。
改餐厅或加节点同步日标题、正文、提示、导航、地图、多点路线、待办。
只用已核实坐标；仅有区域定位则标“区域示意”，名称链接用于准确导航。
同一酒店可只显示一个标记，但路线保留返回酒店再出发的顺序。
小红书攻略只接受对应域名的 HTTPS 链接或分享口令，拒绝 javascript URL 与插入 HTML；标题无法读取时允许用户改写，不假称已看视频。

## 交通住宿
字段、分组和确认状态按 [sections.md](sections.md)；不得将未订安排标为已确认。
交通卡片展示已确认起降地点、日期和时间，注明时区；住宿展示房型、入住退房日期、地址、电话和地图链接。
酒店取消说明合为一行，保留截止时间和重要限制，不显示房价。不把示例标成真实订单。

## 清单：默认最终功能
行李：预先整理的分类清单，分类可折叠，每组可勾选，分类与整体显示按组计算的准备进度（组内多件物品不另计数），完成项划线，刷新后保留。初始清单由AI生成，分类固定。各分类末尾仅放细线“+”新增物品；点物品文字直接修改，勾选框只控制完成状态。Enter或结束输入保存、Esc取消；清空文字并确认删除，不常驻编辑/删除按钮。新增、修改、删除和勾选沿用页面实际存储，默认本地，按用户要求接入其自己的同步服务。保留稳定ID及已勾选状态，删除项不因刷新或默认清单重新合并而恢复。
必买：输入商品名称并添加，可选图片，显示商品总件数。商品行保留小图片、名称与删除入口；图片预览中可上传、换图或移除图。默认没有勾选框、已买进度、名称编辑或独立备注字段。
待办：展示型“出发前要办”提醒列表，按办理时机/截止时间预先整理；每项展示时间、标题与简短说明。部分有明确时间的提醒提供加入日历按钮，正确处理时区；日历入口下载 ICS，导入后由日历提醒，不能声称网页关闭仍通知。取消期限提醒默认提前24小时。默认不提供新增、直接编辑、完成勾选或删除入口，制作时由 AI 从行程识别购票、预约、交通、取消期限等事项，生成带办理时间的提醒；更改行程时由 AI 同步修改相应提醒及顺序。这不是网页中的自动任务管理系统，默认不实现自定义任务或拒绝/去重交互。
仅在使用者明确追加功能时扩展上述默认范围，不因通用“清单”一词自动增加 CRUD。

## 多人多币种记账
严格按 [ledger.md](ledger.md) 实现固定布局、本人花费、币种汇总算法、舍入和验收算例，不另选算法。设置入口仅存在于记账区域，不能放在全局顶部。
默认支持账单录入/编辑/删除、时间排序、备注、照片、平分/自定义分摊、人员管理、本人选择、本位币/常用币种/汇率设置；无账单数据导出导入。
需要云同步时为使用者配置独立存储；只有真实服务验证通过才显示共享同步。本地预览明确仅当前浏览器，不把本地数据称为云同步。
默认使用 assets/template 的可运行代码；保留其按钮行为。layout-example.html 的只读示例仅供参考，不得代替可运行模板。

## 地图服务选择

由执行本Skill的AI在整理旅行资料时选择地图服务，不要求使用者先研究地图配置。
- 中国大陆地点优先高德，海外地点优先Google Maps；港澳台按实际服务覆盖、可用性和使用者偏好选择。根据行程目的地判断，不根据使用者所在地、网页语言、时区或设备定位判断。
- 混合行程按当天或具体地点选择；跨区域的一段路线拆成可用的区域路段，不能强行把整趟旅行都套到同一家服务。使用者明确指定时优先从其要求。
- 地点名直接链接对应导航，保持ⓘ与攻略按钮位置，不新增每个景点的独立导航按钮。同步处理当日路线、地图弹窗链接及坐标缺失时的名称查询回退。
- 基础模板的app.js默认生成Google链接。大陆行程必须实际适配maps/placeLink/routeUrl/routeLinks及地图回退链接，可增加集中式服务选择字段或链接覆盖；只修改说明、JSON或域名替换不算完成。该适配属于允许的模板功能调整，不重建页面布局，也不增加全局设置。
- 依据地图运营方当前官方链接文档生成参数，核对经纬度顺序与坐标系。高德导航需要其支持的坐标或地点信息，不能把OSM的坐标无转换冒充高德坐标；未核实坐标时使用经核实的名称搜索或官方分享链接。
- 全天路线覆盖所有停靠点及往返顺序。服务或交通方式不支持多途经点时按顺序提供分段导航，不只保留起终点，也不冒充完整多点路线。核查当前官方能力，不能声称所有导航模式都支持多点。
- 网页当日地图底图与外部导航分开处理：海外默认OSM并保留署名，中国大陆优先高德底图。由执行Skill的AI引导使用者配置自己的高德JS API Key及安全配置，并在当前平台实现、验证全部点位、编号、连线、全览、放大、点选和日期切换清理；核对坐标系。没有配置或平台无法实现时明确说明，保留路线示意、地点列表和高德外部导航，不冒称已接入高德底图，不借用作者密钥或非官方瓦片接口。
- 在手机端核查地点、路线、弹窗与回退链接选择正确，地图底图失败仍能查看地点和外部导航。不承诺任何服务在所有网络环境都可访问。
