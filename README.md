# 小企鹅旅行手册 🐧

让大家都跟小企鹅一起出发。

这是一份用于 AI 助手的开源 Skill：沿用背包企鹅、椰子、扶桑花和橙紫配色，帮助你制作自己的旅行网页。你提供目的地、日期与旅行需求，AI 按这套规则生成或修改页面。

它不是已经部署的网站，不提供公共数据库、订票或付款服务。随附脚本只准备素材，完整页面仍由 AI 根据需求制作。

## 可以制作什么

- 每日行程：时间节点、转场、餐厅与景点、紧凑攻略链接。
- 当日地图：全部停靠点、序号、往返顺序和多点导航。
- 景点简介：名称旁的小按钮，展开一段介绍。
- 行李、必买、待办清单：勾选、编辑、按日期排序。
- 多人多币种记账：本人承担的旅行花费、付款与分摊、人员结算。
- 手机优先的布局，以及保存到主屏幕时使用的企鹅图标。

这些是 Skill 的制作规则，不是随附素材已经实现的功能。需要哪些功能，可以在请求中说明；本地保存、云同步、访问保护和部署由 AI 按你的环境配置并验证。

## 开始使用

1. 下载本仓库，保留完整的 `build-penguin-travel` 文件夹，不能只复制 `SKILL.md`，否则会缺少图标和参考规则。
2. 在支持 `SKILL.md` 的 AI 工具中，按照该工具的安装方式添加这个文件夹。
3. 调用 `build-penguin-travel`，并说明你的旅行信息。不同工具的安装入口和调用语法可能不同。

可以这样说：

> 用小企鹅旅行手册 Skill，帮我制作一个橙紫配色的旅行网页。我计划去【目的地】，日期是【日期】，同行【人数】人。需要每日行程、地图、行李和记账，手机优先。先用虚构示例预览，不要公开部署。

修改页面时可以说：

> 把第二天下午加一个咖啡店停留，先给方案；我确认后，同步修改时间、导航、当日地图和待办顺序。

如果你的工具不支持安装 Skill，可以让 AI 阅读完整文件夹中的 `SKILL.md` 和它引用的规则，并提供企鹅素材。不要把私人订单或密码放进公开聊天、仓库和页面。

## 可选：准备素材

安装 Python 3 后，在仓库目录运行：

```bash
python3 build-penguin-travel/scripts/scaffold.py --output my-penguin-trip
```

脚本会生成橙紫样式、企鹅图标、主屏幕 manifest、虚构数据和许可文件。输出目录必须是新目录或空目录，脚本会拒绝覆盖已有项目。接下来让 AI 在这个目录里创建完整网页。

## 文件结构

```text
build-penguin-travel/
├── SKILL.md                  # AI 制作流程
├── agents/openai.yaml        # Skill 展示信息
├── assets/                   # 橙紫样式、企鹅图标、虚构数据
├── references/               # 设计、功能、隐私和验收规则
├── scripts/scaffold.py       # 素材准备脚本
└── LICENSE
```

## 数据与隐私

本仓库不含原作者的私人旅行行程、酒店订单、账单、邮箱、访问密码或数据库配置。

每位使用者创建自己的页面和数据存储。本地保存只属于当前浏览器，不能当作跨设备同步。需要云同步时，使用自己的独立服务；需要密码保护时，使用服务端验证，不能只隐藏前端页面。

网页部署和公开分享需要另外确认，不会因调用 Skill 自动公开。
