### 跟小企鹅一起出发吧 🐧
把旅行资料交给 AI，套用一份手机友好的旅行手册。下次换个目的地，还能接着用。

## ✨ 能帮你做什么？

| 功能 | 可以做什么 |
| --- | --- |
| ⏳ 此刻关注 | 重要安排倒计时，自动切换下一项 |
| 🗺️ 行程总览 | 看清城市之间怎么走、每段待几天 |
| ✈️ 已确认安排 | 航班、酒店、取消期限放在一起 |
| 📍 每日行程 | 时间线、当日地图、全天路线；点地点去导航，点 ⓘ 看简介 |
| 📕 攻略收藏 | 把小红书链接或分享口令存到对应活动旁 |
| 🧳 行李清单 | 分类勾选，一眼看到还差什么没准备 |
| 🛍️ 必买榜单 | 添加想买的东西和图片，随时整理 |
| 🔔 待办提醒 | AI 按行程整理、按时间排序，部分可加入日历 |
| 💰 旅行记账 | 多人、多币种、费用分摊，算清自己花了多少、谁该给谁转账 |

页面从上往下看，手机上也方便。记账设置都在记账里；待办由 AI 整理，需要改时告诉 AI 就好。

## 🐾 怎么用？

**会装 Skill？** 把完整的 [build-penguin-travel](build-penguin-travel) 文件夹装到你用的 AI 工具里，然后告诉它去哪、什么时候去、和谁去，再把航班、酒店和想玩的地方发给它。封面让 AI 挑选目的地的经典地标或风景自动生成，颜色随当地风景，不要求加入企鹅。

**不会装也没关系。** 把这个仓库链接发给能读取仓库、运行代码的 AI，再复制这段话，把【】里的内容换成自己的：

> 帮我用 penguin-travel-plan 做一份旅行手册。先看看 build-penguin-travel/SKILL.md，直接套用现成页面，换成我的旅行资料，并根据目的地自动生成封面。我要去【】，时间是【】，同行【】人，航班、酒店和想去的地方是【】。新旅行请用独立 ID，帮我核对路线和时间，也检查一下手机上的显示。默认给我能本地运行、能保存数据的版本。如果我要求发布，而且你有发布功能，就直接帮我发布并给我可访问的链接；没有发布功能，就给我完整项目和打开方法。需要多人同步时，再连接我自己的存储服务。

用 WorkBuddy 这类能发布网页的工具，想直接上线就加一句“做好后帮我发布”；能发布就直接发布，不用再确认一次。只支持本地运行的工具，也能先做出可用版本。

下次旅行，换一份资料再让 AI 套用就行；这次临时想加一站，也可以直接告诉它。

<details>
<summary>💻 想自己先打开示例看看？</summary>

下载并解压仓库。电脑装了 Python 3 的话，在仓库目录运行：

```bash
python3 -m http.server 8000
```

然后打开 [http://localhost:8000/](http://localhost:8000/)。

有 Node.js 也可以运行 `npm run preview`，不用安装依赖。别直接双击 HTML，示例需要通过这个本地服务打开。

</details>

## 🔒 数据怎么保存？

存在你自己的浏览器里，刷新后还在；换设备不会自动同步，清除浏览器数据可能丢失。想和朋友一起记账时，再接你们自己的存储服务。

示例资料都是虚构的，模板不会把数据存到作者的私人账户里。
