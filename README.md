<h1 align="center">跟小企鹅一起出发吧 🐧</h1>
<p align="center">penguin-travel-plan · 一套可以反复使用的旅行网页模板</p>

把旅行资料交给 AI，生成自己的旅行手册。下一次换个目的地，继续套用同一套页面。

## 有哪些功能？

| 功能 | 可以做什么 |
| --- | --- |
| 此刻关注 | 重要安排倒计时，自动切换下一项 |
| 行程总览 | 查看城市之间的交通与旅行阶段 |
| 已确认安排 | 集中查看航班、酒店和取消期限 |
| 每日行程 | 时间线、当日地图、全天路线；点击地点导航，点 ⓘ 看简介 |
| 攻略收藏 | 在对应活动旁保存小红书链接或分享口令 |
| 行李清单 | 分类勾选，查看准备进度 |
| 必买榜单 | 添加商品和图片，管理购物清单 |
| 待办提醒 | AI 根据行程整理，按时间排列，部分支持日历提醒 |
| 旅行记账 | 多人、多币种、费用分摊、本人花费与人员结算 |

手机优先，所有板块从上到下排列。设置只在记账里；待办由 AI 整理，网页内不支持编辑或删除。

## 怎么用？

**支持 Skill 的 AI：** 安装完整的 [build-penguin-travel](build-penguin-travel) 文件夹，再提供旅行资料。

**不会安装 Skill：** 把这个仓库链接交给能读取仓库、运行代码的 AI，复制下面这段话：

> 请使用 penguin-travel-plan 的现成模板，先阅读 build-penguin-travel/SKILL.md。我的目的地是【】，日期是【】，同行【】人，已确定的航班、酒店和想去的地方是【】。请替换旅行资料和封面，复用现有布局与功能，为新旅行使用独立 ID，核对路线和时间，检查手机端后给我可用预览。默认本地运行并保存数据；公开部署前向我确认。

想自己预览：下载并解压仓库，在目录运行 `python3 -m http.server 8000`，打开 http://localhost:8000/。也可以运行 `npm run preview`，无需安装依赖。不要直接双击 HTML。

## 数据存在哪里？

默认保存在使用者自己的浏览器里，刷新后仍保留；换设备不会自动同步，清除浏览器数据可能丢失。需要多人同步时，再连接使用者自己的存储服务。

示例资料为虚构。公开模板不连接作者的私人账户，也不包含真实订单、人员或账单。
