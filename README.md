<h1 align="center">跟小企鹅一起出发吧 🐧</h1>

把航班、酒店、想去的地方和旅行需求交给 AI，整理成一张适合手机查看的旅行网页。

这份开源 Skill 把实际使用中调整过的布局和交互写成规则：从上到下看完整趟旅行，点地点找路、收攻略、整理行李，再算清自己的旅行花费。

**这是供 AI 使用的 Skill，包含制作规则、素材和结构示例。完整网页由 AI 根据你的资料生成；下载仓库不会直接得到已部署的网站。**

## 页面里有什么

默认是一张连续长网页，顶部「行程／行李／必买／待办／记账」导航只负责滚动定位。

| 板块 | 功能与布局 |
| --- | --- |
| 标题与封面 | 旅行标题、日期、天数，目的地地标背景与撕纸边缘 |
| 此刻关注 | 下一件重要事项的倒计时，如取消期限、出发时间；到点后切换下一项 |
| 行程总览 | 城市之间的交通路线、方向和各城市旅行阶段 |
| 已经确认的安排 | 分段航班、中转、酒店房型与取消期限；待购票、待预约另行标注 |
| 每日行程 | 日期切换、时间线、转场、夜宿；当日地图在活动列表之前 |
| 行李清单 | 分类折叠、按组勾选、分类及整体准备进度 |
| 必买榜单 | 添加商品和可选图片，预览内上传／换图／移除图，商品可删除，无勾选框 |
| 待办 | AI 从行程整理的办理时间、期限和说明，部分事项可下载日历提醒 |
| 旅行记账 | 多人、多币种、平分／自定义分摊、本人花费及按人员结算 |

几个小细节也有固定规则：

- **地点名称就是地图链接**，旁边的 ⓘ 展开一小段景点介绍。
- 每条活动标题右侧有 **📕＋**，可保存小红书攻略；链接紧凑显示，可修改和移除。
- 当日地图展示全部地点、编号和顺序，保留回酒店等往返路线。
- 「有空再逛」可以折叠，手机端避免重复文案、大卡片和空白。
- 设置只在记账板块，管理同行人、本人、币种与汇率。
- 「我的旅行花费」只计本人承担的份额，替别人垫付不计作自己的消费。
- 结算建议按人员组合列出各原币种转账金额，并辅助显示约合本位币。
- 保存到主屏幕时使用随附的小企鹅图标。

默认行李内容由 AI 整理，网页内不增删改物品；待办也是展示型提醒，不提供网页内编辑、删除或完成勾选。修改行程时由 AI 同步更新待办。需要扩展功能可以另行说明。

## 怎么使用

### 使用支持 Skill 的 AI 工具

1. 点击 GitHub 的 **Code → Download ZIP** 下载并解压。
2. 保留完整的 `build-penguin-travel` 文件夹，按你的 AI 工具提供的方式安装或导入 Skill。不要只复制 `SKILL.md`，图标、示例和参考规则也需要一起保留。
3. 调用 `build-penguin-travel`，提供旅行资料，请 AI 先制作可用预览。

不同工具的安装入口、调用方式和运行环境不同，本仓库不提供各平台的一键安装器。

### 不会安装 Skill，也可以这样说

把完整文件夹提供给能读取文件的 AI，复制下面这段话：

> 请阅读 build-penguin-travel 文件夹里的 SKILL.md，以及它引用的设计、功能、板块契约、记账和验收规则，用随附的企鹅图标与橙紫配色，为我制作一张手机优先的旅行长网页。各板块从上到下排列，顶部导航只滚动定位。请沿用 layout-example.html 的组件位置，再实现完整功能，不把结构示例当成成品。我的目的地是【】，日期是【】，同行【】人，已确定的航班和酒店是【】，想去的地方是【】。先给可用预览，按验收清单自行检查；公开部署前向我确认。

已有页面可以这样修改：

> 把第二天下午增加一站咖啡店，先说方案。我确认后同步修改时间、地图、导航和待办，保留已有账单、攻略和勾选数据。

## 准备哪些资料

目的地、日期和同行人数即可开始；资料越完整，第一版越接近你的实际需求。

可以提供航班、酒店和取消期限、已订门票、每日想去的地方、不能错过的时间节点，以及餐饮、作息和交通偏好。尚未确定的事项会标为待确认，不会伪造已出票或已预约状态。

请先移除订单号、证件号等不需要显示的信息。

## 关于地图

页面里有两类地图：**城市间行程总览**帮助理解整趟旅行，**当日地图**展示一天内的全部停靠点与顺序。

当日地图默认采用 OpenStreetMap，保留署名；地点名称和全天路线链接可打开外部地图导航。图中的顺序示意线会注明用途，不冒充实际道路导航轨迹。没有配置时不会声称使用了 Google 地图底图。

## 素材与本地预览

需要准备素材时，在仓库目录运行：

```bash
python3 build-penguin-travel/scripts/scaffold.py --output my-penguin-trip
```

需要 Python 3；输出目录必须不存在或为空。脚本准备样式、企鹅图标、manifest、虚构数据与 `layout-example.html`，不会自动生成完整网站、连接数据库或部署。

可以预览结构示例：

```bash
python3 -m http.server 8000 --directory my-penguin-trip
```

打开 http://localhost:8000/layout-example.html 。示例只用于理解布局与部分局部交互，记账是只读虚构算例，地图是结构示意；AI 仍需接入完整功能并验证。完整网站生成后的启动方式以该项目说明为准。

## 分享自己的网页

AI 可以按你的需求生成静态网页，再部署到你选择的托管服务，例如 GitHub 配合 Cloudflare Pages。

- 仅本地保存：数据属于当前浏览器。
- 多人／多设备共享：需要配置自己的独立后端或存储，并实际验证同步。
- 私密访问：需要服务端验证；仅用前端密码弹窗隐藏内容不构成访问保护。

生成预览不等于同意公开；部署和公开分享需要你的明确授权。
