### 跟小企鹅一起出发吧 🐧
把旅行资料交给 AI，套用一份手机友好的旅行手册。下次换个目的地，还能接着用。

## ✨ 能帮你做什么？

- ⏳ **此刻关注**：重要安排倒计时，自动切换下一项。
- 🗺️ **行程总览**：手绘地图展示城市路线、当地地形和停留天数。
- ✈️ **已确认安排**：汇总航班、酒店和取消期限，待购票／待预约各有一张小卡片。
- 📍 **每日行程**：时间线、当日地图和全天路线；点地点去导航，点 ⓘ 看简介。
- 📕 **攻略收藏**：把小红书链接或分享口令存到对应活动旁。
- 🧳 **行李清单**：按分类勾选，电脑多列、手机单列。
- 🛍️ **必买榜单**：添加想买的东西和图片，随时整理。
- 🔔 **待办提醒**：根据行程生成、按时间排序，部分可加入日历。
- 💰 **旅行记账**：多人、多币种、费用分摊，算清个人支出和转账结算。

页面从上往下看，手机上也方便。记账设置都在记账里；待办由 AI 整理，需要改时告诉 AI 就好。

## 🐾 怎么用？

把这个仓库链接或完整项目交给支持 Skill、能读取项目和运行代码的 AI，同时上传自己的旅行资料。可以直接告诉它：

> 我的旅行资料在这里，请读取 build-penguin-travel/SKILL.md，套用这个模板帮我生成旅行页面，并根据目的地自动生成封面。做好后帮我发布，给我网页链接。

尽量提供日期、目的地、同行人数、航班、住宿和想去的地方。AI 会整理资料、补充需要确认的信息，再套用模板生成页面。

AI 会根据自身能力选择发布方式；无法直接发布时，会提供完整项目和发布方法。

下次旅行，换一份资料再让 AI 套用就行；临时想加一站，也可以直接告诉它。

## 💻 本地预览

下载并解压仓库，电脑安装 Node.js 后，在项目目录运行：

```bash
npm run preview
```

然后打开终端显示的网址。不用安装依赖，别直接双击 HTML。

<details>
<summary>🔧 检查旅行资料</summary>

电脑安装 Python 3 后，可以运行：

```bash
npm run validate
```

</details>

## 🔒 数据怎么保存？

默认存在你自己的浏览器里，刷新后还在；换设备不会自动同步，清除浏览器数据可能丢失。发布网页、分享链接也不会自动同步记账数据；需要多人共同记账时，再让 AI 接入你们自己的存储服务。

示例资料都是虚构的，模板不会把数据存到作者的私人账户里。
